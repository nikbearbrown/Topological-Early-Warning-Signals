## What the data are

This file contains daily returns for the Fama-French 49 U.S. industry portfolios. The extracted CSV states that it was created using the `202603` CRSP database and contains both value-weighted and equal-weighted returns for 49 industry portfolios.

The portfolios are constructed at the end of June each year. Firms are assigned to industry portfolios using industry classifications described by the Kenneth French Data Library. The file includes two main data blocks:

1. `Average Value Weighted Returns -- Daily`
2. `Average Equal Weighted Returns -- Daily`

For the analysis in the draft paper, the relevant block is the value-weighted daily return panel unless otherwise stated.

## Date range and shape

The downloaded CSV begins on `19260701` and ends on `20260331`.

The file has 52,440 lines total, including header text, the two return blocks, and the copyright line. Each return block uses a date column followed by 49 industry columns:

`Agric`, `Food`, `Soda`, `Beer`, `Smoke`, `Toys`, `Fun`, `Books`, `Hshld`, `Clths`, `Hlth`, `MedEq`, `Drugs`, `Chems`, `Rubbr`, `Txtls`, `BldMt`, `Cnstr`, `Steel`, `FabPr`, `Mach`, `ElcEq`, `Autos`, `Aero`, `Ships`, `Guns`, `Gold`, `Mines`, `Coal`, `Oil`, `Util`, `Telcm`, `PerSv`, `BusSv`, `Hardw`, `Softw`, `Chips`, `LabEq`, `Paper`, `Boxes`, `Trans`, `Whlsl`, `Rtail`, `Meals`, `Banks`, `Insur`, `RlEst`, `Fin`, `Other`.

## Units and missing values

Returns are reported as daily percentage returns, not decimal returns. A value of `1.25` means 1.25 percent, or 0.0125 as a decimal return.

Missing data are coded as `-99.99` or `-999`, following the Kenneth French Data Library convention. These values should be converted to missing values before analysis.
